Text
orchestration

Type a sentence, hear it. Every feeling in the sentence becomes a parameter, every parameter becomes a musical element.

The idea

01

“OH MY GOD this is the whole thing I was trying to do awhile back where you can type a sentence and then hear how it would sound. based on how happy/sad, how… give n parameters but map each one to a musical element”

His words, verbatim · 1:54 AM, Sept 18

That is the whole brief. N parameters of the sentence’s feeling, each mapped to a musical element. The name he gave it at 1:54 in the morning: text orchestration.

The form

02

“i want a cat (yearning chord) who is black (modify that chord) etc”

His words, verbatim
“i want a cat”
States a chordThe first line puts a harmony on the table. Yearning has a sound.
modify
“who is black”
Modifies itThe next line inherits the chord and changes it. Darker.

This is what makes it better than plain parameter mapping: each line states, the next line modifies. A progression, not a mix. The piece gets form over time because every line inherits the last line’s harmony. Lyrics become modulation.

is a messenger

03

His next insight: it should be a messenger. Send is already a performative act - every message lands and changes something. Make every send a musical event and a conversation becomes a duet you’re composing without trying. Every thread gets its own score, written by accident, just by talking.

The machine

04

Settled shape, two stages. The model never has to understand music.

Stage one · the scorer

Sentence in, coordinates out.

  • happy / sadscore + confidence
  • calm / franticscore + confidence
  • certain / uncertainscore + confidence
feeds

Stage two · the fixed table

Designed once, by a human.

  • valencemode · major / minor
  • arousaltempo
  • confidenceamplitude

Stage one is exactly the decision-model shape: structured choices plus confidence, no text generation - which is where Jev-style System One models fit, cheap enough to run live and continuously. Stage two is a fixed mapping table, written once. The model scores, the instrument plays. The taste lives in the table, not the model.

Open questions

06
  1. Question 1

    What’s the instrument?

    One voice that shifts timbre with the sentence, or a small ensemble where each parameter owns an element.

  2. Question 2

    What does “modify” do?

    When the next line changes the chord: darken the timbre, shift to minor, drop the register - or all three.

  3. Question 3

    Whose table?

    Does the mapping table ship fixed, one instrument designed once - or does each user tune their own.
